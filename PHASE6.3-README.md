# Phase 6.3 — Offline Network Guide

- Adds a sixth Guide destination while preserving Home, Signal, Speed, History and Settings.
- Adds a bundled Hindi/English searchable troubleshooting guide with 15 topics.
- Works offline and adds no third-party dependency or permission.
- Reuses existing signal and speed diagnostics; does not duplicate them.
- Does not claim to boost RF power, tower coverage or carrier bandwidth.

## APK size note
This knowledge pack is text-based and intentionally lightweight. It improves offline utility but will not make the APK 20 MB. Do not add meaningless padding or an unverified model just to reach a size target. A genuine on-device model should only be added after selecting a documented model, checking license, RAM/storage use and Redmi 9 performance.

## Build
GitHub Actions: `:app:assembleDebug`. Verify the run and download the `anb-network-booster-debug` artifact before installing.
